# HAnumans

Home Assistantで実現できること、工夫、発見を共有し、次のアイデアにつなげるサイトです。

単なる自動化レシピ集や網羅的なマニュアルではなく、「こんなこともできるんだ」「自分でも試してみたい」と発見するための場所を目指します。

**HAnumans** — *Once you enter the HA jungle, there's no way out.*\n\n日本語コピー：**HAに沼った人々**。
